# Династия — сайт

Самостоятельный проект текущей версии сайта. В этой папке находятся только файлы сайта и лицензия шрифта. Аудит, скриншоты, презентационные оболочки и промежуточные скрипты находятся за её пределами.

## Структура

```text
dinastiya-site/
├── index.html
├── assets/
│   ├── css/main.css
│   ├── js/main.js
│   ├── vendor/gsap/gsap.min.js
│   ├── fonts/golos.ttf
│   └── images/
│       ├── brand/
│       ├── hero/
│       ├── doctors/
│       ├── clinic/
│       ├── articles/
│       ├── reviews/
│       ├── banks/
│       └── works/
└── licenses/Golos-Text-OFL.txt
```

## Локальный запуск

В этой папке выполните:

```powershell
python -m http.server 8767 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8767/. Сборка и установка зависимостей не требуются. Папку можно перенести отдельно: локальные ресурсы подключены относительными путями.

## Редактирование

- Разметка и содержание — `index.html`.
- Оформление и адаптация — `assets/css/main.css`.
- Меню, поиск, формы, телефонная маска и взаимодействия — `assets/js/main.js`.
- Изображения и шрифт подключены локально; карта и видеоплеер используют исходные внешние iframe.

Дальнейшие изменения сайта следует делать в этом проекте. Файлы старого макета в `mockups/home-v2` больше не являются основной рабочей версией.

## Текущий этап

Это статическая версия согласуемого дизайна, ещё не тема WordPress. Формы работают в режиме макета и не отправляют заявки. При переносе в WordPress нужно подключить содержимое из админки и отправку форм, сохранить исходные URL и SEO-данные, настроить индексацию. Локальный проект пока содержит `noindex`.
